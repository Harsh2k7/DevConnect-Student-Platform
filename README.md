# 🚀 DevConnect Student Platform

**DevConnect** is a student-focused project collaboration platform designed to connect students, projects, and technical skills in one place.

Students can discover active projects, find teammates, post their own project ideas, showcase their profiles and skills, and apply to projects. Project owners can review applications and accept or decline candidates, while administrators can manage the platform.

## ✨ Key Features

* 🔐 Student Registration & Login
* 👨‍💻 Student Dashboard
* 🚀 Project Marketplace
* ➕ Post Your Own Project
* 🤝 Join / Apply to Projects
* 📋 Manage Project Applications
* ✅ Accept / Decline Applications
* 👤 Student Profiles
* 🛠️ Skills & College Information
* 🛡️ Admin Dashboard
* 👥 User Management
* 📊 Project Management
* 🚪 Secure Session Logout
* 🎨 Modern Responsive UI
* ⚡ Startup & Login Animations

## 🗄️ Database

The main database is:

```text
devconnect_db
```

Main tables:

```text
users
projects
project_requests
```

### 👤 Users

Stores student/admin account information, college, skills and role.

### 🚀 Projects

Stores project title, description, required skills, project owner and status.

### 📋 Project Requests

Stores applications submitted by students for projects.
